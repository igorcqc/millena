# ConversionOS - Design System Skill

Version: 1.0

---

# Purpose

This skill defines the visual foundation used by all projects created inside ConversionOS.

The goal is to create consistent, premium, accessible and conversion-focused interfaces.

The Design System exists to prevent random visual decisions and ensure every page follows a coherent visual language.

---

# Scope

This skill applies to:

- Landing pages
- Sales pages
- Lead generation pages
- Product pages
- Marketing websites
- Campaign pages

It defines:

- Typography
- Color usage
- Spacing
- Layout principles
- Components
- Visual hierarchy
- Interaction patterns

---

# Dependencies

This skill depends on:

- reference/core-rules.md

# Design Philosophy

The interface should communicate:

- Trust
- Clarity
- Premium perception
- Simplicity
- Professionalism

The design should never exist only for decoration.

Every visual choice must support:

- Understanding
- Attention
- Confidence
- Conversion

---

# Visual Hierarchy

Every page must have a clear hierarchy.

The user should immediately understand:

1. What is this?
2. Is this relevant to me?
3. Why should I trust this?
4. What should I do next?

The design must guide the user's attention naturally.

---

# Layout System

## Container

Default:

Desktop:

1200px - 1280px maximum width

Mobile:

16px - 24px side padding

Avoid content stretching across extremely wide areas.

---

## Grid

Prefer simple structures:

- One column
- Two columns
- Three columns

Avoid unnecessary complexity.

Every grid must have a clear purpose.

---

# Spacing System

Use consistent spacing based on an 8px grid.

Preferred values:

8px

16px

24px

32px

48px

64px

80px

96px

Avoid arbitrary spacing values.

Consistency creates visual quality.

---

# Typography System

Typography must prioritize:

- Readability
- Hierarchy
- Scannability

Recommended font families:

- Inter
- Geist
- Manrope

Avoid decorative fonts unless the brand specifically requires them.

---

# Typography Hierarchy

Recommended structure:

## Display / Hero

Used for the main message.

Purpose:

Create immediate attention.

---

## Heading

Used for section titles.

Purpose:

Organize information.

---

## Body

Used for explanations.

Purpose:

Provide clarity.

---

## Small Text

Used for:

- Labels
- Supporting information
- Metadata

---

# Color System

Every project should define:

## Primary Color

Used for:

- Main CTA
- Important actions
- Brand emphasis

---

## Secondary Color

Used for:

- Supporting elements
- Highlights

---

## Neutral Colors

Used for:

- Backgrounds
- Text
- Borders
- Cards

---

# Color Rules

Never use colors randomly.

Every color must have a purpose.

Avoid:

- Too many colors
- Low contrast combinations
- Decorative gradients without function

---

# Buttons

Buttons are conversion elements.

They must be:

- Highly visible
- Easy to understand
- Easy to click

Every button must define:

## Primary Action

The most important user action.

Example:

Request quote

Schedule consultation

Buy now

---

## Secondary Action

Lower commitment action.

Example:

Learn more

See examples

---

# Button Rules

Buttons should have:

- Clear text
- Strong contrast
- Comfortable size
- Visible hover state
- Visible focus state

Avoid:

- Generic text like "Click here"
- Multiple competing primary buttons

---

# Cards

Cards should only exist when they improve:

- Organization
- Comparison
- Scanning

Avoid excessive card usage.

A page full of cards creates visual noise.

---

# Images

Images should support communication.

Prioritize:

- Real people
- Real products
- Real environments
- Contextual photography

Avoid generic stock imagery.

Images should answer:

"Why is this image helping conversion?"

---

# Icons

Use consistent icon styles.

Rules:

- Same visual family
- Same stroke style
- Similar sizing

Never mix different icon systems.

---

# Motion Design

Animations should be:

- Subtle
- Fast
- Purposeful

Use motion to:

- Guide attention
- Provide feedback
- Improve perception

Never use animation only to impress.

---

# Responsive Principles

Mobile experience has priority.

Every component must consider:

Mobile

↓

Tablet

↓

Desktop

Never design desktop first and simply shrink.

---

# Component Consistency

Before creating a new component ask:

Does this already exist?

Can an existing component solve this?

Will this appear again?

If yes, create a reusable pattern.

---

# Common Mistakes

Avoid:

- Random spacing
- Too many colors
- Excessive animations
- Poor contrast
- Tiny buttons
- Decorative sections
- Template-like appearance
- Inconsistent components

---

# Implementation Rules

The AI must:

1. Read this skill before creating interfaces.

2. Follow existing patterns.

3. Prefer reusable components.

4. Maintain visual consistency.

5. Avoid introducing new design patterns without justification.

6. Prioritize conversion over decoration.

# AI Instructions

When designing any interface:

Think like a senior product designer.

Do not ask:

"How can I make this look impressive?"

Ask:

"How can this help the user understand, trust and act?"

Every design decision must have a reason.
