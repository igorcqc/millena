# ConversionOS - FAQ Skill

Version: 1.0

---

# Purpose

This skill defines how to use FAQ sections to resolve remaining doubts and objections without cluttering the main page flow.

The FAQ is the last line of objection handling before the final CTA.

---

# Scope

Applies to the FAQ section of any landing page.

# Core Principle

An FAQ section is not a place to dump miscellaneous information.

It exists to answer real questions and objections that would otherwise stop a visitor from converting.

---

# Selecting Questions

Prioritize questions that reflect:

- Common objections (price, timeline, results, trust)
- Practical concerns (how it works, what's included, next steps)
- Comparison concerns ("how is this different from X?")

Avoid questions with obvious answers already covered elsewhere — that wastes attention.

---

# Question Framing

Write questions the way a real visitor would ask them, in their own words.

Good: "Is there a contract or can I cancel anytime?"

Weak: "Contract Terms" (this is a label, not a question)

---

# Answer Writing Rules

- Answer directly in the first sentence
- Keep answers concise; link to more detail elsewhere if needed
- Use the answer to reinforce value or reduce risk, not just state facts
- Never introduce a new objection without resolving it in the same answer

---

# Number of Questions

5-8 questions is typically sufficient.

Too few leaves real objections unanswered. Too many suggests the page itself failed to communicate clearly, and dilutes attention from the CTA.

---

# Placement

Place the FAQ after objection-handling and offer details, and before the final CTA — so visitors act immediately after their last doubts are resolved.

---

# Interaction Pattern

Use an accordion (expand/collapse) pattern to keep the page scannable, with only one or a few questions expanded by default.

Ensure accordions are keyboard-accessible (see 11-accessibility.md).

---

# Common Mistakes

Avoid:

- Generic questions unrelated to real objections
- Answers that are vague or evasive
- Burying the FAQ so deep visitors never reach it
- Using the FAQ to hide unfavorable information instead of addressing it honestly

---

# Implementation Rules

The AI must:

1. Derive FAQ questions from the objections identified in 01.
2. Write questions in natural visitor language.
3. Write direct, concise, honest answers.
4. Place the FAQ after objection handling and before the final CTA.
5. Implement accessible accordion interaction.

---

# Quality Checklist

□ Questions reflect real objections

□ Written in natural visitor language

□ Answers are direct and honest

□ 5-8 questions, not excessive

□ Accessible accordion interaction

---

# AI Instructions

Treat every FAQ answer as a final opportunity to remove a reason not to convert.

If an honest answer would hurt conversion, that signals a product or offer problem, not a copy problem — do not obscure it.
